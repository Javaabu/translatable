- PHP 8.4 or higher
- Laravel 12 or 13

Optional:

| Package | For |
| --- | --- |
| [javaabu/forms](https://github.com/Javaabu/forms) ^2.0 | The [Blade components](basic-usage/blade-components.md) |
| [javaabu/manifest](https://github.com/Javaabu/manifest) ^1.0 | Shipping the [React components](basic-usage/react-components.md) to your app |
| [@javaabu/forms](https://github.com/Javaabu/react-forms) and [@javaabu/i18n](https://github.com/Javaabu/i18n) (npm) | The React components |
| [inertiajs/inertia-laravel](https://inertiajs.com) ^2.0 | Sharing the languages with Inertia pages |
| [javaabu/helpers](https://github.com/Javaabu/helpers) ^1.74 | The `AdminLanguage` model, a language that's a helpers `AdminModel` ([Languages](basic-usage/languages.md#admin-pages)) |

The models work without any of them.
